# Рендер текста

`mngl::two_d::Frame2D::draw_text()` добавляет глифы в существующий 2D-батчер. На каждый видимый глиф создаётся лёгкий quad-instance, но совместимые последовательные глифы группируются в draw calls, а не отправляются на GPU по одному. Шрифт лениво растеризует используемые глифы в текстурный атлас и переиспользует их между кадрами. Пока текст состоит из уже закешированных символов, повторная отрисовка не растеризует их и не загружает атлас заново.

```cpp
mngl::two_d::font typeface{
    mngl::gpu::device::global(),
    "imgui/misc/fonts/Roboto-Medium.ttf",
    48.0f
};

mngl::two_d::text_draw_options options;
options.height = 0.05f;
options.tint = mngl::color{ 1.0f, 1.0f, 1.0f, 1.0f };

window.clear();
window.draw([&](mngl::two_d::Frame2D& frame)
{
    frame.draw_text(typeface, "FPS: 60", { 0.05f, 0.95f }, options);
});
window.display();
```

`height` задаёт размер шрифта в координатах 2D-сцены; `top_left` — верхний левый угол первой строки. Шрифт должен использовать тот же GPU device, что и renderer, и жить до отправки command buffer с кадром. Конструктор без `device` использует `mngl::gpu::device::global()`.

## Большие документы

Храните документ построчно и меняйте только затронутые строки. Для `text_document` требуется передать мировую область видимости: renderer вычислит диапазон строк, пересекающих её по вертикали, и пропустит остальные до разбора UTF-8 и создания глифов. Автоматического переноса строк пока нет: каждая запись документа рисуется одной строкой.

```cpp
mngl::two_d::text_document log;
log.append_line("Application started");
log.append_line("Waiting for connection...");

// Обновляем только изменившуюся строку.
log.set_line(1, "Connected");

mngl::two_d::text_draw_options options;
options.height = 0.025f;
options.clip_bounds = mngl::rectangle{ 0.05f, 0.1f, 0.9f, 0.8f };

window.draw([&](mngl::two_d::Frame2D& frame)
{
    frame.draw_text(typeface, log, { 0.05f, 0.9f }, options);
});
```

`clip_bounds` используется для CPU-culling и пропуска целых глифов, которые полностью вне области. Это не GPU-маска: частично выступающий глиф будет нарисован целиком. Для точного отсечения задайте `options.scissor` в пикселях render target. Для однострочного или небольшого многострочного текста используйте перегрузку со `string_view`; она просматривает всю строку, поэтому для больших прокручиваемых документов предпочтителен `text_document` с ограниченной областью видимости. Очень длинная отдельная строка также просматривается целиком, даже если большая часть её глифов отсечена.

## Метки сцены

Для множества надписей сначала отсеките их bounds по видимой области сцены, затем вызывайте `draw_text` только для оставшихся меток. `clip_bounds` ограничивает глифы одной надписи, но не заменяет пространственный индекс для сотен тысяч или миллионов меток.

```cpp
for (const scene_label& label : labels)
{
    if (!visible_world_bounds.intersects(label.bounds))
    {
        continue;
    }

    frame.draw_text(typeface, label.text, label.position, options);
}
```

Каждый вызов `draw_text` добавляет не более одной записи hit-test для всей надписи, а не отдельную запись на глиф. Текущая реализация раскладывает UTF-8 по кодовым точкам с базовым попарным кернингом; сложная формация письменностей, лигатуры и bidi пока не поддерживаются. Файл шрифта должен быть доверенным TrueType-файлом.
