# Координаты и view

## Логические координаты

У 2D API начало координат находится в левом нижнем углу, ось `y` направлена вверх. Без пользовательского view короткая сторона цели равна `1`, а длинная соответствует соотношению сторон:

- цель `800 × 600` имеет `coordinate_size()` `{ 1.333..., 1 }`;
- цель `600 × 800` имеет `coordinate_size()` `{ 1, 1.333... }`.

`mngl::rectangle` задаётся как `{x, y, width, height}`. Например:

```cpp
mngl::rectangle bounds{0.1f, 0.2f, 0.3f, 0.4f};
```

## Пользовательский view

`mngl::view` задаёт прямоугольную область мира:

```cpp
mngl::view camera{mngl::rectangle{0.0f, 0.0f, 4.0f / 3.0f, 1.0f}};
window.set_view(camera);
scene_texture.set_view(camera);
```

View окна и каждой текстуры хранится отдельно. Если формат цели не совпадает с пропорциями заданной области, видимая область расширяется вокруг центра по одной оси. Изображение не растягивается, а заданная область остаётся видимой.

Задавайте или сбрасывайте view между кадрами через `set_view()` и `reset_view()`. `coordinate_size()` возвращает размер фактически видимой области текущего view. При `window.clear(scene_texture)` используется view целевой текстуры, а не view окна.

## Большие координаты дерева

`tree_renderer.hpp` хранит мировые центры узлов и размер раскладки в `double`. `tree_draw_area` также принимает координаты и размеры в `double`, поэтому большая раскладка не теряет расстояние между соседними узлами.

Перед отправкой геометрии на GPU из мировой позиции вычитается `tree_draw_options::coordinate_origin`; в `float` преобразуются уже локальные координаты. `clip_bounds` задаётся в мировых координатах и обрезает длинные рёбра до преобразования. GPU остаётся на FP32 и не требует поддержки FP64.

Для дерева большого размера заранее постройте раскладку и передайте мировой центр камеры как начало координат:

```cpp
auto layout = mngl::two_d::measure_tree_layout(model, options);
mngl::two_d::tree_draw_area area{0.0, 0.0, layout.size.x, layout.size.y};

options.coordinate_origin = camera_center;
options.clip_bounds = visible_world_area;
mngl::two_d::draw_tree_model_parallel(frame, typeface, model, layout, area, options);
```

Проекция кадра должна быть настроена относительно того же начала координат камеры. `draw_tree_model_parallel()` использует готовую раскладку; видимые узлы и рёбра можно предварительно вычислить через `tree_draw_culler`.
