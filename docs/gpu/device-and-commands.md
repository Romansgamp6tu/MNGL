# Устройство и командные буферы

## Устройство

`mngl::gpu::device` — копируемая ручка на общее состояние GPU device SDL. Копии `device`, созданные ресурсы и командные буферы удерживают SDL device живым; он уничтожается после освобождения последней такой ручки. Обычный путь использует общедоступный singleton:

```cpp
const mngl::gpu::device& device = mngl::gpu::device::global();
```

При необходимости можно создать отдельный `device` с набором поддерживаемых форматов шейдеров. GPU-ресурсы должны создаваться на том же устройстве, с которым они используются. Перегрузки MNGL, принимающие `device`, удерживают его состояние. Перегрузки низкого уровня, принимающие `SDL_GPUDevice*`, заимствуют указатель: вызывающий должен держать SDL device живым до уничтожения всех созданных через них обёрток. `claim_window()` и `release_window()` связывают SDL window с GPU device; `render_window` делает это автоматически.

`wait()` ожидает завершения GPU-команд и возвращает признак успеха. Для swapchain доступны режим HDR и режим вертикальной синхронизации; низкоуровневая настройка делается через `device`.

## Запись и отправка команд

`mngl::gpu::command_buffer` приобретает командный буфер у устройства и принимает команды загрузки или рендеринга:

```cpp
const auto& device = mngl::gpu::device::global();
mngl::gpu::command_buffer commands(device);

// Записать операции загрузки или render pass в commands.

commands.submit();
```

`submit()` явно отправляет команды и позволяет получить ошибку непосредственно в месте вызова. `cancel()` явно отбрасывает записанные команды. Если действующий command buffer уничтожен без одного из этих вызовов, его деструктор отменяет его без выброса исключений.

Command buffer нельзя использовать, перемещать или уничтожать с потока, отличного от того, на котором он был приобретён. При уничтожении с другого потока он пишет ошибку в SDL log и не может отменить буфер. Получение swapchain-текстуры также должно происходить на главном потоке окна. Командный буфер и задействованные ресурсы должны относиться к одному GPU device.

Низкоуровневый `acquire_swapchain_texture(window)` нужен при ручном построении прохода в окно. Для обычного 2D-кода используйте `render_window`.
