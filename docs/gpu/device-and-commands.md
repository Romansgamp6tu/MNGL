# Устройство и командные буферы

## Устройство

`mngl::gpu::device` владеет GPU device SDL. Обычный путь использует общедоступный singleton:

```cpp
const mngl::gpu::device& device = mngl::gpu::device::global();
```

При необходимости можно создать отдельный `device` с набором поддерживаемых форматов шейдеров. GPU-ресурсы должны создаваться на том же устройстве, с которым они используются. `claim_window()` и `release_window()` связывают SDL window с GPU device; `render_window` делает это автоматически.

`wait()` ожидает завершения GPU-команд и возвращает признак успеха. Для swapchain доступны режим HDR и режим вертикальной синхронизации; низкоуровневая настройка делается через `device`.

## Запись и отправка команд

`mngl::gpu::command_buffer` приобретает командный буфер у устройства и принимает команды загрузки или рендеринга:

```cpp
const auto& device = mngl::gpu::device::global();
mngl::gpu::command_buffer commands(device);

// Записать операции загрузки или render pass в commands.

commands.submit();
```

Явно вызывайте `submit()`, чтобы получить ошибки отправки непосредственно в месте вызова. Если действующий command buffer уничтожен без явного submit, его деструктор пытается отправить его без выброса исключений.

Command buffer нельзя использовать или перемещать с потока, отличного от того, на котором он был приобретён. Получение swapchain-текстуры также должно происходить на главном потоке окна. Командный буфер и задействованные ресурсы должны относиться к одному GPU device.

Низкоуровневый `acquire_swapchain_texture(window)` нужен при ручном построении прохода в окно. Для обычного 2D-кода используйте `render_window`.
