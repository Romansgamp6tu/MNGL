# Поверхности и цвета

## Загрузка изображений

`mngl::surface` загружает файл по пути через SDL_image:

```cpp
mngl::surface image("assets/background.png");
mngl::texture gpu_image(image);
```

`surface` владеет загруженным SDL surface/animation. Метод `raw()` возвращает указатель на текущий кадр без передачи владения. Для анимированных форматов `animated()` сообщает, есть ли несколько кадров, а `on_frame_changed` вызывается при переключении кадра. В стандартном цикле кадры обновляются автоматически через `Input::continue_work()`, поскольку `surface` зарегистрирована как `Iupdatable`.

Конструктор `mngl::texture(surface)` загружает в GPU только текущий кадр. Он не обновляет текстуру автоматически при последующих изменениях анимации поверхности.

`mngl::pixel_format` описывает форматы пикселей SDL. Для форматов GPU существует отдельный тип `mngl::gpu::texture_format`; это разные пространства форматов.

## Цвет

`mngl::color` хранит RGBA-компоненты в диапазоне `[0, 1]`. При передаче целых чисел компоненты задаются в диапазоне `[0, 255]`:

```cpp
mngl::color floating{ 0.2f, 0.6f, 1.0f, 1.0f };
mngl::color bytes{ 51, 153, 255, 255 };
mngl::color html{ "#3399FFFF" };
```

Последний компонент альфа-канала можно опускать: по умолчанию он равен полной непрозрачности. Для интеграции с графическими API есть преобразования в `glm::vec3` / `glm::vec4`, `SDL_Color` и целочисленный RGBA-код.

Дополнительно `color` поддерживает представления HSV/HSL, смешивание, вычисление яркости и преобразования premultiplied alpha. Это утилиты цвета, а не состояние GPU-текстуры.
