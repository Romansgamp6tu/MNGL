# События

`mngl::event_manager` преобразует события SDL в типизированные структуры MNGL. Подписка задаётся типом события и callback-функцией:

```cpp
auto resize_subscription = mngl::event_manager::on<mngl::windowResized>(
    [](const mngl::windowResized& event)
    {
        logger.info(
            "Window size: ",
            event.size.x,
            " x ",
            event.size.y);
    });
```

Структуры событий для окна, клавиатуры, мыши, дисплеев, gamepad/joystick, touch, drag-and-drop, аудиоустройств, сенсоров и других событий находятся в `event.hpp`. Большинство событий окна наследуются от `windowEvent` и содержат идентификатор окна; конкретные события добавляют свои данные.

Для обычного приложения достаточно цикла `Input::continue_work()`: он обрабатывает очередь SDL, после чего подписчики получают события. `Input` также предоставляет упрощённый доступ к состоянию клавиатуры и мыши, если не нужна событийная модель.

`on<T>()` возвращает move-only `mngl::event_connection`. Подписка активна, пока живо это соединение; уничтожение или `disconnect()` отключает её. Поэтому результат `on()` нужно сохранить, иначе временное соединение сразу отключит callback. Если отключение вызвано из другого потока, оно дождётся уже выполняющегося callback; сам callback может отключить свою подписку, в том числе при вложенной отправке события.

Не захватывайте в callback объекты по ссылке, если они могут быть уничтожены раньше соединения. Callback получает событие как `const`-ссылку и не должен сохранять эту ссылку после возврата.

Типизированный интерфейс также позволяет объявить собственный тип, унаследованный от `mngl::eventBase`, зарегистрировать на него `on<T>()` и отправлять его через `event_manager::emit()`.
