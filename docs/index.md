# Документация MNGL

MNGL — C++23 библиотека поверх SDL3 для окон, событий, физического ввода,
аудио, 2D и SDL GPU. Она предоставляет как готовые интерфейсы для обычных
задач, так и доступ к GPU-ресурсам и проходам. Большая часть кода находится
в заголовках; Dear ImGui собирается в отдельную библиотеку.

## С чего начать

Для собственного приложения откройте [руководство по подключению](getting-started/using-mngl.md):
оно показывает CMake-проект, первое окно, настройку runtime и зависимостей.
Для разработки самого MNGL используйте [сборку из исходников](getting-started/building.md).

Документация соответствует текущему `main`. Сверяйте набор API с версией
пакета: input v2 и аудио могут отсутствовать в более ранних релизах.
Автоматическая поставка и линковка SDL3_mixer ещё ожидают обновления CI/CD;
его [подключение описано отдельно](core/audio.md#sdl3-mixer).

## Соглашения руководства

Примеры используют публичные заголовки MNGL. Физический ввод обновляется
через `input::next_frame()`; прежнее имя `input::continue_work()` и старые
`input::is_key_*`/методы мыши
сохранены для миграции и помечены `[[deprecated]]`. Готовые названия игровых
действий задаёт проект через `action_map`.

Большинство оконных и графических операций сообщают об ошибке исключением
`sdl_error`; обычные аудиовызовы бросают `audio::audio_error`, а явные `try_` API возвращают `std::expected`. Соглашения о
потоках и времени жизни ресурсов приведены в руководстве каждого модуля.
Проектные решения input v2 и аудио находятся в отдельном разделе навигации.
