# Документация MNGL

MNGL — библиотека на C++23 поверх SDL3. Она включает управление окнами и
устройствами ввода, аудио, высокоуровневую 2D-отрисовку и низкоуровневый SDL
GPU API. Этот сайт предназначен для тех, кто впервые подключает библиотеку,
и для тех, кому нужен отдельный справочник по конкретному модулю.

## Учебный маршрут

Для первого приложения пройдите страницы по порядку:

1. [Подключите MNGL](getting-started/using-mngl.md): выберите пакет, соберите
   CMake-проект и запустите окно.
2. [Нарисуйте первый кадр](2d/quick-start.md): фигура, цикл кадра и
   отрисовка без пользовательских ресурсов.
3. [Разберитесь в цикле, координатах и времени жизни](getting-started/concepts.md):
   когда обрабатывать ввод, обновлять игру и завершать кадр.
4. Добавьте [управление через действия](core/input-recipes.md),
   [спрайты и атласную анимацию](2d/sprite-animation.md) или
   [текст](2d/text-rendering.md).
5. Для звука и сохранений переходите к руководствам по
   [аудио](core/audio.md) и [файлам](core/storage.md).

Если приложение не собирается или окно не запускается, используйте
[разбор ошибок](getting-started/troubleshooting.md). Готовые каталоги проектов
с CMake и полными исходниками собраны на странице
[учебных примеров](examples.md).

## Как читать примеры

Пример помечен как **полная программа**, если он содержит все нужные include,
`main()` и обработку ошибки. Примеры с пометкой **фрагмент** вставляются в уже
созданный объект или цикл — описание рядом с кодом перечисляет эти предпосылки.
Пути `assets/...` относятся к данным приложения: примеры без отдельного
упоминания не включают картинки, звук или шрифты. Для 2D/GPU также нужен
совместимый runtime с каталогом `shaders/` и доступными shader tools.

Код использует публичные заголовки `<MNGL/...>`. Внутренние файлы
`MNGL/detail/` предназначены для реализации библиотеки и не являются
стабильным API.

## Версии, ошибки и соглашения

Документацию нужно сверять с версией исходников или development-пакета:
выпущенный пакет может быть старше ветки, для которой собирается сайт.
В частности, input v2, атласная анимация и отдельные новые аудиовызовы
появлялись постепенно. Если символ не находится, сначала сравните версию
заголовков с [картой публичных модулей](reference/index.md).

Физические события и время обновляются один раз за итерацию через
`mngl::input::next_frame()`. Для движения используйте `delta_time()`, а для
разового нажатия — `pressed()`. Игровые действия задаёт приложение через
`action_map`; их можно разделять по контекстам меню и игры.

Обычные API часто возвращают объект напрямую и сообщают об ошибке
исключением. Явные операции `try_*` там, где они предусмотрены, возвращают
`std::expected`. Страницы модулей указывают, где выполняется работа, кто
владеет ресурсом и что должно жить дольше кадра.
